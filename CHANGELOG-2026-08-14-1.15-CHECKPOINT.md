# WerePires 1.15 — Phone Foundation Checkpoint

Checkpoint created August 14, 2026 (CDT) before continuing the major native cell-phone port.

## Added

- Native Paper dialog cell-phone interface and tagged, color-model phone item.
- UUID-based `phone-data.json` persistence with atomic replacement saves.
- Thrall active-character-name integration for phone identity.
- Phone issuing, status, reload, opening, and session-reset commands.
- Contacts with favorites and blocking.
- Direct messages with unread state and offline delivery.
- Do-not-disturb, silent, vibrate, refresh, and phone-color settings.
- Saved GPS positions with distance and direction output.
- Private notes with editing, pinning, and deletion.
- Persistent schema foundations for social posts, group chats, and game records.

## In progress after this checkpoint

- Simple Voice Chat private and group calls.
- Social feed, handles, follows, and reactions.
- Group chat creation, membership, and messaging.
- Native phone games and records.
- Importing legacy Skript YAML phone data.

## Validation

- Clean Maven package build completed successfully on Java 21 for Paper 1.21.10.
- The generated checkpoint test build keeps the network protocol kill switch disabled.
