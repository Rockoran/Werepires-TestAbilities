# WerePires 1.15.3

Date: 2026-08-15 (America/Chicago)

## Added

- Adds plugin-managed delivery of the WerePires server resource pack on player join.
- Uses `https://download.mc-packs.net/pack/4f52f1c8b41931ef9bd00b008fe8d308519d9b5b.zip`.
- Verifies the download using SHA-1 `4f52f1c8b41931ef9bd00b008fe8d308519d9b5b`.
- Leaves the pack optional and sends no custom prompt, matching the supplied empty prompt and resource-pack ID settings.
- Adds configuration for enabling delivery, URL, SHA-1, required status, and join delay.
- Reports declined or failed pack delivery without interrupting normal joins.

## Deployment note

Disable either `server-resource-pack.enabled` or the equivalent `server.properties` entries if the server already sends this pack, so players do not receive two requests.
