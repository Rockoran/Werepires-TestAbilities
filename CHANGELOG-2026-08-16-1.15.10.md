# WerePires 1.15.10 — 2026-08-16

This release audits the entire fork rather than only the cellphone work suggested by the branch name.

## Command completeness fixes

- Restored `/pow admin bloodmoon <start|stop|status>`. Its handler, help entry, and tab completion already existed, but its Paper Brigadier node was missing, which made the command unreachable.
- Restored handler-supported `/pow` aliases: `abilities`, `fae`, `toggle_permadeath`, and `togglepermadeath`.
- Restored the plural/singular vault aliases `listtomevaults` and `listominouscurevault`.
- Restored beacon aliases `delete`, `desecrate`, and `repair`.
- Registered the previously orphaned admin commands `/stash_third_book` and `/stash_fourth_book`.
- Tagged the stashed third cure book with its hidden Cure Book 3 identity so reading it advances the cure sequence.

## Lifecycle completeness fix

- Added the missing `StarterKitManager.shutdown()` call during plugin disable so its final persistent state is always flushed with the other managers.

## Full-fork documentation

- Added `FULL-FORK-SOURCE-AUDIT.md` with every command root, subcommand family, alias, permission, listener registration path, manager/service family, and every branch-changed Java source file.
- Reconciled the exhaustive source audit with `CHANGELOG-FROM-VAMPIRESMP-1.0.6.md` and the public website changelog.
- Confirmed that the branch changes span commands, managers, listeners, Fae systems, Werewolves, tomes, thralls, worlds, beacons, ghosts, roles, sessions, resource packs, networking, configuration, and packaging—not only cellphones.

## Verification

- Java 21 clean Maven package succeeds.
- Development artifact: `WerePires-1.15.10-TESTBUILD.jar`.
- All Bukkit command roots have executors.
- All Java permission literals are declared in `plugin.yml`.
- Every non-placeholder Bukkit listener is registered directly, self-registered, or registered by its owning manager.
- Every manager that declares an explicit shutdown hook is called directly or by its owning manager.
