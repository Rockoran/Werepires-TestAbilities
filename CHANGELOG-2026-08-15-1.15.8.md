# WerePires 1.15.8 — 2026-08-15

- Changed the plugin-managed base resource pack from a replacing request to a stacked resource-pack request.
- The resource pack configured in `server.properties` now remains loaded when WerePires sends its own pack.
- Added a stable UUID for the WerePires base pack so repeat requests update the same stack entry instead of adding duplicates.
- When both packs contain the same asset path, the WerePires pack remains the higher-priority layer because it is sent afterward.
