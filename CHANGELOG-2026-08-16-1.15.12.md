# WerePires 1.15.12 — optional automatic tier-down skins

- Added `/skin tierdown off` to keep the player's current skin when their vampire stage decreases.
- Added `/skin tierdown on` to restore the default behavior where both promotions and demotions change skins automatically.
- The preference is stored per player in their existing skin data file and survives reconnects and restarts.
- Tier-up skin changes remain automatic while tier-down changes are off.
- Manual `/skin apply`, curing/human restoration, cured skins, and ghost skins are unaffected.
