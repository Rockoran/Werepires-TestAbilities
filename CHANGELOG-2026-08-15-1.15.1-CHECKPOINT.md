# WerePires 1.15.1 checkpoint

Date: 2026-08-15 (America/Chicago)

## Purpose

- Creates a stable checkpoint after completing the native CellPhone 1.15 port.
- Delivers call-only mute/deafen and two-way speakerphone support through Simple Voice Chat.
- Retains the development-only `TESTBUILD` suffix.
- Retains the source-level network protocol kill switch in its disabled state.

## Functional changes

- Replaces hidden SVC group transport with private phone audio channels while leaving normal proximity routing active.
- Adds call-only microphone mute; nearby players can still hear the muted caller through proximity chat.
- Adds call-only deafen; normal proximity audio remains audible.
- Adds a moving two-way speakerphone: nearby players hear remote callers and can speak back through the phone.
- Limits each call to one active speakerphone owner to reduce feedback and duplicate relays.
- Excludes call members from speaker output to prevent hearing the remote caller twice.
- Adds `/callmute`, `/calldeafen`, and `/speaker` commands and matching active-call phone buttons.
- Adds configurable speaker listening and transmission radii under `phone.calls.speaker`.
- Cleans up listeners, audio channels, mute state, and speaker state on hangup, disconnect, timeout, and shutdown.
- Excludes historical nested build output from packaged resources, preventing recursive `target/classes` entries in the jar.

## Verification

- Clean Maven packaging with Java 21 passes against Simple Voice Chat API 2.6.0.
- The produced artifact is `WerePires-1.15.1-TESTBUILD.jar`.
- Live audio behavior still requires a three-client server test: remote caller, phone owner, and nearby speaker participant.

This checkpoint is committed and tagged on the development branch only. It is not merged.
