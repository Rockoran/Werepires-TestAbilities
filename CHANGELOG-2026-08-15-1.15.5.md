# WerePires 1.15.5

Date: 2026-08-15 (America/Chicago)

## Fixed

- Replaces SVC `PlayerAudioListener` call input with `MicrophonePacketEvent`, so phone routing receives the actual speaker microphone instead of audio delivered to a listener.
- Fixes callers hearing themselves and prevents nearby received speech from being misidentified as the listener speaking.
- Keeps phone playback packets outside microphone capture by design, removing the need for playback-category recursion filtering.
- Routes the configured base resource pack through the existing `VampireTexturePackManager` instead of a competing second join listener.
- Removes duplicate resource-pack requests that could replace or race the existing base/vampire pack stack.
- Updates the existing base-pack URL and SHA-1 to the supplied `4f52f1c8b41931ef9bd00b008fe8d308519d9b5b` pack.
- Preserves the supplied empty prompt and optional-pack behavior.

## Cause

The previous phone implementation used an SVC listener intended for received player audio, not raw microphone input. Separately, version 1.15.3 introduced a second resource-pack manager even though `VampireTexturePackManager` already controlled join-time and vampire pack delivery.

This development checkpoint is not merged.
