# WerePires 1.15.4

Date: 2026-08-15 (America/Chicago)

## Added

- Restores the original CellPhone Skript shortcut: hold a phone and shift-right-click another player to add them to contacts.
- Refreshes the clicked player's identity from their active thrall profile at interaction time.
- Displays and confirms the active character name, falling back to the Minecraft username only when no active character name exists.
- Prevents adding yourself or duplicating an existing contact.
- Stops shift-right-click from opening the normal phone menu.
- Adds the interaction hint to an empty Contacts screen.

Contacts remain UUID-backed so messages and settings stay attached to the correct account while the visible identity uses the character profile.

This development checkpoint is not merged.
