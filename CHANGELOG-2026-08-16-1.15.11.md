# WerePires 1.15.11 — whole-fork completeness pass

This release is not a cellphone-only update. It records repairs found while auditing every command, manager, listener, ability, service, resource, persistence path, and lifecycle in the full WerePires fork.

## Commands and permissions

- Restored Brigadier routes for `ability status`, `ability help`, Fae `list`, `help`, and `free`, plus long-form vampire/werewolf `clear_stage_cap` and `clear_promotion_ban` aliases.
- Corrected admin help/usage paths that omitted `/pow admin`.
- Updated `plugin.yml` usage for roles, vampires, starter kits, sessions, skins, ghosts, and internal phone aliases.
- Made role and session administration honor `vampiresmp.admin` rather than requiring operator status.
- Corrected `/starterkit` to use the declared player permission while preserving admin permissions for configuration and giving kits.
- Restricted thrall admin-only help entries to players with `thralls.admin`.

## Registration and lifecycle

- Removed duplicate registration of Holy Word, the three Way tomes, and the Blood Moon attribute listener.
- Kept `TomeManager` and the plugin entry point as the single owners of those listeners.
- Retained explicit manager shutdown/final-save coverage, including the starter-kit manager repair from 1.15.10.

## Data, config, and migration

- Moved active world/template selection and the fourth-revival-book unlock into `state.yml` so live game state no longer rewrites `config.yml`.
- Migrates those values even if `state.yml` already exists.
- Added missing animal blood-draw damage and cooldown defaults.
- Removed unused config accessors rather than advertising settings that had no runtime effect.
- Added safe copy-only migration from `plugins/VampireSMP/` to Bukkit's renamed `plugins/WerePires/` folder. Current files are never overwritten and the legacy folder remains as a backup.
- Corrected remaining runtime paths and messages to use the actual WerePires data folder.

## Documentation and verification

- Corrected WerePires branding and command metadata.
- Added `scripts/audit_source.py`, which currently verifies all 185 Java files, 35 Bukkit command roots, 58 listener-capable classes, 40 concrete abilities, 50 manager classes, 42 explicit lifecycle owners, declared permissions, and 273 literal config reads.
- Passed `mvn clean package` on Java 21 and produced `WerePires-1.15.11-TESTBUILD.jar`.
