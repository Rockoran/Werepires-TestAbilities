# WerePires 1.15.2

Date: 2026-08-15 (America/Chicago)

## Fixed

- Stops WerePires phone audio packets from being captured and retransmitted by the same SVC player-audio listener.
- Adds a phone volume-category filter so private-call and speakerphone output cannot re-enter the router.
- Adds a synchronous routing guard as a second layer of loop protection if packet category metadata is unavailable or altered.
- Prevents the resulting recursive `StaticAudioChannel.send` calls, `StackOverflowError`, and SVC packet-queue overload.

## Cause

Simple Voice Chat invokes registered player audio listeners for plugin-generated audio-channel packets as well as the original voice packet. Version 1.15.1 treated its own emitted packet as new input and retransmitted it indefinitely.

## Verification

- Clean Java 21 Maven package required.
- Expected development artifact: `WerePires-1.15.2-TESTBUILD.jar`.
- Live SVC retest should confirm calls no longer recurse and that mute, deafen, and two-way speakerphone still work.

This checkpoint remains on the development branch and is not merged.
