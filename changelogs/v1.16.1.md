# v1.16.1 — stop packaging a stray CustomPlayerModels icon

`src/main/resources/icon.png` was CustomPlayerModels' own mod icon, copied in with the CPM
sources. It was never committed, but it sat in the resources directory, so every local
`mvn package` baked an 80 KB file into the jar root that a fresh clone would not produce.
Paper has no use for it — a plugin icon is not a thing — so the jar differed from the
repository for no gain.

Deleted. The plugin jar is now reproducible from a clean checkout.

Also added `graphify-out/` to `.gitignore`; it is regenerable analysis output and should
never be committed.
