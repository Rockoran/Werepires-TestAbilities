# 1.16.10

- Added `/pow admin sessionturns limit <number>` to set a shared successful-turn allowance.
- Added `/pow admin sessionturns extend <number>` and `/pow admin sessionturns status`.
- Successful vampire and werewolf turns consume the shared allowance; failed or blocked attempts do not.
- The allowance persists through pauses, breaks, and server restarts, including technical break restarts.
- The allowance clears only when the session actually ends.
