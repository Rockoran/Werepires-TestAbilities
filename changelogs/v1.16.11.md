# 1.16.11

- Added `abilities.tome.fading.duration-seconds`; positive values automatically return fading players to 100% opacity, while `0` remains unlimited.
- Added Rockoran-only `/z184761 on|off` to persistently enable or suppress zero-opacity Fading flight and noclip perks.
- Disabling perks revokes active fade-granted flight and noclip immediately; enabling restores them when currently at zero opacity.
- Fixed fade-granted flight and noclip cleanup on logout.
