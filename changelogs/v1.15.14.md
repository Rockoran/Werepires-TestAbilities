# v1.15.14 — MC 1.21.10 — 2026-08-20

## Fixed
- **Scrying's directional arrow no longer flickers or disappears.** `SessionManager` runs a task
  every second that overwrites *every* player's action bar with the session status whenever the
  server is out-of-session or pre-session. The Scrying arrow redraws every 4 ticks, so the status
  task was stomping it roughly every fifth frame — the arrow appeared broken, most visibly when
  testing outside an active session.
- The same fix repairs **thrall locate** and **findmaster**, which share the directional indicator.

## Changed
- `VampireTrackingManager.hasActiveIndicator(Player)` is new: it reports whether a viewer
  currently has a directional arrow running.
- The session status action bar now skips any player with an active indicator, so the arrow owns
  the action bar for its duration instead of the two fighting over one line.

## Notes
- The arrow glyphs are Private Use Area characters (``–``) supplied by the server
  resource pack. If an arrow renders as a missing-glyph box rather than not appearing at all,
  that is a resource-pack problem and not this bug.
