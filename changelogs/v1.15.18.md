# v1.15.18 — MC 1.21.10 — 2026-08-20

## Fixed
- **The `/pow admin config` GUI no longer renders ragged.** Paper's `multiAction` dialog defaults
  to **two columns**, and the menu mixed three button widths — 320 for settings, 150 for
  navigation, 200 for reload. A wide setting button and a narrow "Back" ended up sharing a row,
  so rows never lined up and the effect got worse the further GUI scale moved from the default.
- Values are no longer over-truncated. `shorten()` cut labels at 24 characters, which elided most
  coordinate strings and long paths even though the button had room for them.

## Changed
- The config browser and the edit dialog are now **one column** (`DialogType.columns(1)`) with a
  single uniform button width, so every row is the same shape at any GUI scale.
- Layout is driven by three constants — `COLUMNS`, `BUTTON_WIDTH` (400) and `VALUE_CHARS` (40) —
  instead of magic numbers scattered across six `ActionButton.create` calls.
- Truncation now derives from `BUTTON_WIDTH`, so widening buttons widens what fits rather than
  needing a second edit.

## Notes
- `PAGE_SIZE` is unchanged at 7. With one column that is a taller menu, but pages stay short and
  the nav buttons remain reachable without scrolling.
