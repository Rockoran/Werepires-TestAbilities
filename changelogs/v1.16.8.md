# 1.16.8

- Added `/pow admin sessionsetup`, a five-step dialog for initial building, pre-break gameplay, break duration, post-break gameplay, and final building.
- Added confirmation, status, cancellation, boss bars, timed warnings, and persistent restart recovery for scheduled sessions.
- Reused the normal WerePires break pause/resume, warning-sound, broadcast, and boss-bar system.
- Added `/pow admin extendbreak <minutes>` and `/pow admin extendsession <minutes>`.
- Prevented manual session commands and legacy GameStart timers from conflicting with an active scheduled session.
