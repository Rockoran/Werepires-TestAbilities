# WerePires 1.15 — Native Voice Calls Checkpoint

Checkpoint created August 14, 2026 at 16:00 CDT.

## Added

- Added native private and multi-party group calls through Simple Voice Chat.
- Added hidden, password-protected, non-persistent OPEN voice groups so proximity voice remains audible.
- Added contact calling and group-call buttons to the phone dialogs.
- Added `/answer`, `/decline`, and `/hangup` commands.
- Preserved `/cpacceptcall`, `/cpdeclinecall`, and legacy `/cphanghup` aliases.
- Added 30-second ringing timeouts and missed-call messages.
- Added DND, offline, busy, and voice-client availability checks.
- Added participant join/leave/decline notices and automatic call destruction.
- Added quit and plugin-shutdown cleanup so transient voice groups cannot strand players.
- Isolated all optional Simple Voice Chat API types behind a runtime hook so servers without it still load WerePires.

## Validation

- Maven package build completed against Paper 1.21.10 and Simple Voice Chat API 2.6.0 using Java 21.
- Call state is memory-only and is never written into `phone-data.json`.
- The network protocol kill switch remains disabled in the TESTBUILD artifact.
